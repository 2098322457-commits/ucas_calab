1.本次修改加入指令以及语义如下：
csrrd rd, csr_num   把csr值读入rd寄存器

csrwr rd, csr_num   把rd值写入csr，并将csr旧值存入rd

csrxchg rd, rj, csr_num     把rj的值作为掩码，选择性将rd写入csr，并将csr整个旧值存入rd

syscall code 
系统调用保存当前pc，
ERA ← 本指令 PC` ；`PRMD[2:0] ← CRMD[2:0]` ；`CRMD[2:0] ← 0` ；`ESTAT.Ecode ← 0x0b` 、`EsubCode ← 0` ；`PC ← EENTRY`

ertn 
异常返回，修改crmd，pc回到era

2.csr_num对应不同的csr寄存器
crmd记录当前状态，运行中主要修改[1:0]表示特权级（0=内核，3=用户），[2]中断使能，[3]使用直接地址模式（在复位时设置）
prmd记录前一状态，设计与crmd相同
estat记录异常状态，[21:16]Ecode 0xb为系统调用
era为返回地址，系统调用时存pc
eentry存异常入口地址
